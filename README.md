# الرصد والتحكم في الفضاء الرقمي

موقع ثابت (GitHub Pages) + فاحص آلي يعمل على GitHub Actions.

## كيف يعمل
1. `scanner/config/seeds.txt`: أضف النطاقات الأولية (واحد في كل سطر). يتوسع الفحص تلقائياً عبر الروابط الخارجية (.sa)، والنطاقات البديلة للمخالفين (DNS)، وروابط صفحات المخالفين.
2. كل 6 ساعات (أو تشغيل يدوي من Actions) يفتح الفاحص كل نطاق بمتصفح بلا واجهة ويقبل فقط ما كان `.sa` أو يحمل مؤشرات سعودية (ر.س، +966، المدن، السجل التجاري…).
3. التصنيف بالكلمات المفتاحية في `scanner/config/keywords.json`:
   - **درجة أولى** (بث مباشر / IPTV) ⇒ **مخالف** + لقطة شاشة محفوظة في `data/screenshots/`.
   - **درجة ثانية** (أفلام ومسلسلات) ⇒ **للمراجعة** (لا يمكن آلياً التمييز بين المرخص وغيره).
   - غير ذلك ⇒ غير مخالف (لا يُعرض).
4. النتائج في `data/findings.json`، وتظهر في تبويب «المواقع والمتاجر المرصودة». زر «إصدار تقرير» يصدر PDF فيه الرابط ولقطة الشاشة واسم الفاحص وخط التوقيع.

## تشغيل محلي
```
cd scanner && npm ci && npx playwright install chromium
npm test
node scan.mjs --max 10
```
