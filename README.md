# التحكم والرصد في الفضاء الرقمي

موقع ثابت (GitHub Pages) + فاحص آلي يعمل على GitHub Actions.

## كيف يعمل
- **مرصد الإنفاذ:** أخبار محلية وعالمية (الملكية الفكرية، وزارة الموارد البشرية، النيابة العامة) تُجلب كل 6 ساعات على GitHub Actions من بحث أخبار Google (RSS) إلى `data/news.json`. المصادر والكلمات وفلاتر الصلة في `scanner/config/news-sources.json`.
- **فحص المواقع:** إجراءان، كلاهما داخل المتصفح:
  1. **بلاغات أصحاب الحقوق:** رفع ملف Excel/CSV بالروابط فتظهر بطاقات.
  2. **التفتيش الاستباقي:** سحب مواقع من جدول Google (أو ملف) حسب التاريخ.
  ثم «إصدار تقرير» يصدر PDF فيه الرابط والنتيجة والصورة الملصقة واسم الفاحص وخط التوقيع.
- **سجل التقارير:** لوحة إحصائيات حسب النتيجة ونوع المواد والإجراء.

## تشغيل محلي لجالب الأخبار
```
cd scanner && npm ci
npm test
node news.mjs
```

## تسجيل الدخول
- **افتراضياً (بدون قاعدة بيانات):** يعمل الدخول بحسابات محلية داخل المتصفح. أول زيارة تعرض «إنشاء حساب المشرف»، ومن «حسابي» يضيف المشرف المفتشين والمشرفين ويوقفهم ويعيد تعيين كلمات مرورهم. كلمات المرور تُخزَّن مشفّرة (PBKDF2 مع ملح) وتُقيَّد المحاولات الخاطئة ويُسجَّل الخروج عند الخمول.
- **حدّ هذا الوضع:** الحسابات خاصة بكل متصفح وتحمي واجهة الموقع فقط، ولا تحمي البيانات من شخص يملك الجهاز. الحماية الحقيقية والحسابات المشتركة تأتي من قاعدة البيانات (القسم التالي)، وعند ضبطها يستخدم الموقع نفس شاشة الدخول مع حسابات Supabase.
- **التقارير الدولية:** تُعدَّل من `data/intl-reports.json` (المؤشرات وتعريفاتها وموعد الإصدار السنوي).
- **شعار التقرير:** ضع ملف الشعار في `assets/saip-logo.png`.

## التخزين المشترك (Supabase)
بدون إعداد يعمل الموقع محلياً (البيانات في متصفح كل موظف). لمشاركة قوائم المواقع والتقارير والإحصائيات بين الموظفين:

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` ونفّذه (ينشئ الجدولين ويفعّل الحماية RLS).
3. **Authentication → Providers → Email**: عطّل «Allow new users to sign up»، ثم أضف حسابات الموظفين من **Authentication → Users → Add user** (بريد + كلمة مرور).
4. من **Project Settings → API** انسخ `Project URL` و`anon public` وضعهما في `config.js`:
   ```js
   window.CFG = { supabaseUrl: "https://xxxx.supabase.co", anonKey: "eyJ..." };
   ```
5. ادفع التعديل؛ ستظهر شاشة تسجيل دخول، وتُحفظ القوائم والتقارير للجميع.

مفتاح `anon` عام بطبيعته؛ الحماية من تسجيل الدخول وسياسات RLS: غير المسجّل لا يرى شيئاً، والمسجّل يقرأ ويضيف، ولا يمكن تعديل أو حذف التقارير.
