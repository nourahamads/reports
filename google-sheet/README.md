# ربط الموقع بـ Google Sheet

1. أنشئوا Google Sheet جديداً، ثم **الإضافات ← Apps Script**.
2. الصقوا محتوى `Code.gs` وغيّروا قيمة `TOKEN` إلى نص سري طويل.
3. **نشر ← نشر جديد ← تطبيق ويب**: التنفيذ كـ «أنا»، ومن يملك الوصول: «أي شخص» (أو «المؤسسة» إن وُجدت حسابات Workspace).
4. انسخوا رابط التطبيق (ينتهي بـ `/exec`) مع الرمز السري.
5. عند أول استدعاء تُنشأ ورقتا «المواقع» و«التقارير» بعناوينهما تلقائياً.
