# السوق السعودي — متابعة يومية

لوحة ثابتة لمتابعة السوق السعودي (تاسي)، تُنشر مع الموقع على GitHub Pages في المسار `/saudi-market/`.

## المحتوى
- **حركة اليوم:** افتتاح وأعلى وأدنى وإغلاق مؤشر تاسي، ونطاق حركة 10 شركات قيادية مقارنة بإغلاق اليوم السابق، وجدول قابل للبحث والترتيب.
- **أبرز 6 شركات:** أكبر 3 شركات بالقيمة السوقية (أرامكو، الراجحي، معادن) وأفضل 3 أداءً منذ بداية 2026 (بترو رابغ، MIS، المملكة القابضة)، مع قراءة نتائج النصف الأول 2026 والتوقع القادم والمخاطر.

## البيانات
كل الأرقام في مجلد `data/` بصيغة JSON، ويمكن تحديثها دون تعديل الصفحة:

| الملف | المحتوى |
|---|---|
| `stocks.json` | أسعار الشركات القيادية (افتتاح، أعلى، أدنى، آخر سعر، الكمية) |
| `tasi.json` | مؤشر تاسي لآخر جلسة |
| `companies.json` | التقييم والأداء وأهداف المحللين للشركات الست |
| `fin.json` | بنود القوائم المالية للنصف الأول 2026 و2025 (بالمليون ريال) |
| `notes.json` | القراءة التحليلية والتوقعات والمخاطر |

المصادر: مباشر، أرقام، أرامكو، MarketScreener، TradingView. البيانات لقطة بتاريخ 20 أكتوبر 2026 ومتأخرة، وليست توصية استثمارية.
